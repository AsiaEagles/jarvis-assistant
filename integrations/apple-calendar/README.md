# Apple Calendar entegrasyonu

İlk hedef salt okunur erişimdir; etkinlik oluşturma veya silme sonraki aşamada değerlendirilir.

Olası yollar:
- macOS üzerinde yerel bir yardımcı uygulama/komut satırı köprüsü.
- iCloud CalDAV, gerekli uygulama parolası ve desteklenen kimlik doğrulamasıyla.

Güvenlik:
- Parola veya uygulama parolasını Git deposuna koyma.
- Önce test takvimi ve sahte verilerle dene.
- Takvim içeriğini üçüncü taraf bir servise göndermeden önce açıkça izin ver.

Bu klasör şu anda yalnızca plan içerir; çalışan entegrasyon henüz yok.
